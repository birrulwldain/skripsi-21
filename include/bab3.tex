\begin{enumerate}
    \item \textbf{Studi Literatur} \\
    Studi literatur dilakukan untuk membentuk landasan teoretis yang kokoh bagi simulasi spektrum emisi atom dalam kondisi \textit{Local Thermodynamic Equilibrium} (LTE). Proses ini melibatkan analisis mendalam terhadap:
    \begin{enumerate}
      \item \textbf{Kalkulasi Intensitas Spektral}: Menggunakan distribusi Boltzmann untuk menghitung populasi tingkat energi sesuai persamaan \eqref{eq:bab2_eq11}.
      \item \textbf{Kalkulasi Rasio Ionisasi Plasma}: Menggunakan persamaan Saha untuk menentukan rasio antara atom terionisasi dan netral sesuai persamaan \eqref{eq:bab2_eq27}.
      \item \textbf{Profil Garis Spektral Gaussian}: Menggunakan pelebaran Doppler (Gaussian, \eqref{eq:bab2_eq30}) untuk memodelkan bentuk garis spektral secara akurat.
    \end{enumerate}
    Data transisi atom yang digunakan dalam simulasi divalidasi dengan merujuk pada basis data NIST \citep{Kramida2023}.

    \item \textbf{Pemodelan Simulasi Spektrum Emisi Atom} \\
    Simulasi spektrum emisi atom dilaksanakan dalam kondisi LTE, dengan asumsi plasma memiliki distribusi energi termal yang seragam dan dikendalikan oleh suhu plasma (\(T\)) dan densitas elektron (\(n_e\)). Intensitas garis spektral ditentukan oleh probabilitas transisi dan populasi tingkat energi, sedangkan pelebaran garis dimodelkan menggunakan profil Gaussian.

    Secara matematis, simulasi menghitung intensitas relatif dan mengaplikasikan profil Voigt:
    \begin{equation}
    I_{\text{rel}} = \frac{N g_k A_{ki} \exp\left(-\frac{E_k}{k_B T}\right)}{Z} \label{eq:bab3_eq1}
    \end{equation}
    \begin{equation}
    I(\lambda) = I_{\text{rel}} \cdot G(\lambda - \lambda_{ij}, \sigma) \label{eq:bab3_eq2}
    \end{equation}
    di mana \(I_{\text{rel}}\) adalah intensitas relatif, \(A_{ki}\) probabilitas transisi, \(Z\) fungsi partisi, dan \(G\) fungsi profil Gaussian. Hyperparameter untuk proses simulasi dirangkum pada Tabel~\ref{tab:hyperparameter}.

    \item \textbf{Perancangan Model Informer} \\
    Tahap ini melibatkan perancangan dan pelatihan model \textit{Informer} untuk memprediksi komposisi multi-elemen dari spektrum emisi masukan. Model ini memanfaatkan mekanisme \textit{ProbSparse Self-Attention} untuk menangani data sekuensial panjang secara efisien.

    \textbf{Arsitektur Model}:

Model ini menerima input spektrum emisi 1D, memproyeksikannya ke dimensi model, menambahkan \textit{Positional Encoding}, dan memprosesnya melalui beberapa lapisan \textit{encoder} sebelum menghasilkan prediksi multi-label.

    \textbf{Proses Pelatihan}:
    Model dilatih dengan tujuan meminimalkan *loss* dan memaksimalkan F1-Score pada data validasi.
    \begin{itemize}
        \item \textbf{Fungsi \textit{Loss}}: Digunakan \textbf{MultiLabelFocalLoss} dengan \texttt{gamma=2.0} dan \texttt{pos\_weight} untuk mengatasi ketidakseimbangan kelas.
        \item \textbf{Optimizer:} Digunakan \textbf{AdamW} dengan laju pembelajaran awal \texttt{1e-4}.
        \item \textbf{Penjadwal Laju Pembelajaran:} Digunakan \textbf{OneCycleLR} untuk mengatur laju pembelajaran secara dinamis.
        \item \textbf{Ukuran Batch Efektif:} Ukuran \textit{batch} 25 dengan 4 langkah akumulasi gradien menghasilkan ukuran \textit{batch} efektif 100.
        \item \textbf{Pelatihan Presisi Campuran:} Pelatihan menggunakan presisi campuran (FP16) melalui \texttt{torch.cuda.amp} untuk efisiensi.
        \item \textbf{Early Stopping dan Checkpointing:} Pelatihan berhenti jika F1-Score validasi tidak meningkat selama 6 \textit{epoch}, dan model dengan F1-Score terbaik akan disimpan secara otomatis.
    \end{itemize}
